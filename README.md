# Hidden Leaders

Браузерная многопользовательская настольная игра: комнаты, скрытые лидеры,
карты героев и журнал игровых событий. Статус: активная разработка; интерфейс
на Next.js 14, сервер на FastAPI. Клиент работает в современном браузере,
сервер — с Python 3.11, сборка клиента — с Node.js 24. Карточные изображения
в `src/front/public/images` являются игровыми ресурсами; актуального снимка
запущенного интерфейса в репозитории пока нет.

## Запуск

Из `src/back`:

```sh
python -m venv .venv
# Активируйте .venv для вашей оболочки.
python -m pip install -r requirements.txt
python run.py
```

Из `src/front` во втором терминале:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:3000`; API по умолчанию находится на
`http://localhost:8000`. Для другого сервера задайте `NEXT_PUBLIC_API_URL`
перед сборкой клиента. Для другого клиентского origin настройте серверный
`CORS_ORIGINS`. Параметры БД и запуск сервера описаны в
[README backend](src/back/README.md).

## Проверки и структура

- `src/back`: `python -m pytest` — правила игры, редьюсер, проекции,
  команды и HTTP-интеграция; внешние сервисы не требуются.
- `src/front`: `npx tsc --noEmit` и `npm run build` — типы и production-сборка.
- [Браузерные e2e-тесты](tests/e2e/README.md) запускаются отдельно с
  работающим приложением и браузером; базовый CI их не выполняет.
- [Серверная документация](src/back/README.md) — endpoints, конфигурация и
  event sourcing. Исторический сервер: [legacy README](src/back/legacy/README.md).

CI запускает backend и frontend отдельно при push и pull request. Успешный
CI подтверждает эти автоматические проверки; игровые анимации и полноценная
партия требуют отдельной браузерной проверки.
